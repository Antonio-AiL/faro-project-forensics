El análisis es estático y no ejecuta código del cliente. No es una certificación de seguridad. Pueden existir falsos positivos y falsos negativos.Analysis is static and does not execute customer code. It is not a security certification. False positives and false negatives are possible.

LimitacionesLimitations

La revisión estática puede pasar por alto reflexión, ofuscación, comportamiento en ejecución y secretos en archivos binarios o textos grandes no inspeccionados. Sin antivirus, ejecución en sandbox, base CVE de dependencias, evaluación de licencias ni pruebas de rendimiento. Los ZIP anidados se hashean pero no se abren. Sólo texto UTF-8. Se presupone una entrada estable; las comprobaciones de descriptores y timestamps reducen, pero no eliminan, carreras en un sistema de archivos hostil.Static review can miss reflection, obfuscation, runtime behavior and secrets in uninspected binary/large text files. No antivirus, sandbox execution, dependency CVE database, license adjudication or performance testing. Nested ZIPs are hashed but not opened. UTF-8 text only. Input is assumed quiescent; descriptor and timestamp checks reduce, but cannot eliminate, races on a hostile filesystem.

Los informes conservan nombres relativos de archivos (excepto nombres evidentes con credenciales o correos), hashes, identificadores e imports. Pueden seguir siendo confidenciales. Las salidas HALT contienen sólo el alcance parcial inspeccionado. Los artefactos lógicos no mezclan metadatos temporales.Reports retain relative filenames (except obvious credential/email-bearing names), hashes, identifiers and import names. These can still be confidential. HALT outputs contain only the partial inspected scope. No temporal metadata is mixed into logical artifacts.
